# Bundled fonts

All three faces are licensed under the SIL Open Font License 1.1, which
permits bundling and redistribution. Files are latin-subset woff2 builds;
non-Latin text falls back to the system stack (see DESIGN.md § Typography).

| File | Family | Source | License |
|---|---|---|---|
| `fraunces-var.woff2` | Fraunces (variable: opsz, wght, SOFT) | github.com/undercasetype/Fraunces (via Google Fonts build) | SIL OFL 1.1 |
| `atkinson-hyperlegible-next-var.woff2` | Atkinson Hyperlegible Next (variable: wght) | Braille Institute (via Google Fonts build) | SIL OFL 1.1 |
| `commit-mono-400.woff2` | Commit Mono 400 | commitmono.com (via Fontsource build) | SIL OFL 1.1 |

The OFL requires that the fonts themselves are not sold standalone and that
reserved font names are respected; it places no requirements on the software
that bundles them. Full license text: https://openfontlicense.org
